# Riko AR media pipeline

- `prepare_mindar_targets.py` prepares the 54 printed page targets and copies their page/video placement data to `src/data/arPageTargets.json`.
- `mindar-compile.html` compiles those page images to `public/ar/book-pages.mind` in the local browser; `write_mindar_bundle.py` receives the compiled data.
- `compress_mindar_bundle.mjs` Brotli-compresses the MindAR target file. Cloudflare Pages serves the `.mind.br` bytes with `Content-Encoding: br`; the browser transparently decodes them before MindAR reads the target data. Vite dev/preview serves decoded bytes at `/ar/book-pages.mind`.
- `transcode_videos.py` creates VP9 alpha clips from the 12 ProRes 4444 masters, keys the Riko mascot, and concatenates transparent page clips into transparent recap videos. It also creates H.264 color/matte fallbacks for Safari.
- `remove_video_backgrounds.py` uses the official lightweight rembg U2Netp ONNX model for the other 23 animal, vehicle, and weather clips. It writes transparent VP9 and Safari color/matte fallbacks. Put the 4.6 MB model at `tmp/models/u2netp.onnx` before running it.
- `build_video_presentation.py --pack` scans every matte frame to record conservative foreground bounds in `src/data/arVideoPresentation.json` and builds H.264 side-by-side color/matte clips. A single decoded video supplies both textures on Safari, so a moving silhouette cannot drift away from its colors. Use `--pack-only` to keep measured bounds while building missing packed clips.

AR presentation uses a page-anchored, camera-facing cutout with a planted bottom edge, a soft contact shadow for grounded subjects, and user sizing controls. The full animation's foreground union determines the crop; media pixels and the originals are unchanged. The camera-facing orientation prevents the video turning into a thin rectangle at oblique angles. These are 2D video billboards with spatial placement, not reconstructed 3D objects or depth occlusion.

QA commands: `node scripts/ar/verify_presentation.mjs` validates all measured crops, page layouts, and 504 viewing poses; `python scripts/ar/verify_packed_alpha.py` compares every packed matte frame with the original alpha. With Vite running, `/scripts/ar/packed-media-qa.html` decodes and renders every packed clip in the browser, checking alpha against the corresponding WebM. `/scripts/ar/presentation-qa.html` and `?packed=1` run the real scanner against a synthetic camera feed of the prepared page images, with tilt, rotation and brief occlusion controls. These local-only harnesses are not build entry points and are not shipped to Pages. They do not validate physical-camera focus, lighting, or Safari hardware decoding.

The 12 ProRes source clips with true alpha masters are DV01, DV06, GT02, GT05, GT09, GT10, HTTN01, HTTN03, HTTN07, HTTN12, HTTN13, and HTTN15. U2Netp removes the background from the other 23 page clips. All 54 page slots use the transparent page or recap videos; Safari uses packed H.264 color/matte, with separate streams retained as a compatibility fallback.
